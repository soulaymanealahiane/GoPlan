# GoPlan messaging

**A clear start to university.**

GoPlan combines a useful starting point before university with an editable degree roadmap students can return to throughout their studies. Supporting copy should name the continuing utility plainly: keep courses and semesters together, locate and move courses, track progress, keep notes and export the roadmap.

The university offer still starts with a reviewed program and agreed student cohort. This positioning does not change AI allowances, pricing, institutional approvals, or academic requirements. Avoid promising automatic registration or guaranteed graduation dates.

The shared outlined GoPlan wordmark remains the approved cover-derived lettering. Apparel pairs the circular G with that wordmark in a small horizontal chest placement, without slogans or extra decoration. Use green on light garments and the ivory variant on dark garments. The original slogan is retained in the website hero, page metadata, public/planner footers and planner welcome. Supporting copy explains the ongoing editing utility. The owner-supplied cover retains the same slogan.
